# Inflatable Letters 充气字母

实时 3D 充气气球字 / 照片气球 demo，基于 three.js，单文件 `index.html`。

## 功能
- **文字气球**：任意文字（含中文），6 种字体；逐字设置 10 种图案、4 种材质（光面 / 铝膜 / 果冻 / 哑光）、配色、膨胀度、褶皱
- **照片气球**：上传或拖入照片 → 抠图（透明通道 / 背景色洪泛 / 浏览器内 AI 抠图）→ 充气成气球，照片贴在正面
- 拖拽旋转、点击字母"戳一下"、导出 PNG

## 原理
字形或抠图轮廓 → 模糊圆角 → 有符号距离场（EDT）→ 圆弧截面"充气"成高度场 → 拉普拉斯平滑成枕头状 → 缝边褶皱 → 正反两面在接缝处闭合成网格，配合 `MeshPhysicalMaterial` + 环境光照。

## 运行
需要通过 HTTP 打开（ES module）：

```bash
python3 -m http.server 5178
```

然后访问 http://localhost:5178
